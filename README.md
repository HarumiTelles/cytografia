# Segurança Digital: criptografia e hash

Projeto de estudo em Python com duas partes:

- `cifra_substituicao.py`: criptografia por dicionário (insegura, com letras maiúsculas, minúsculas e números).
- `hash_simples.py`: hash simples somando valores ASCII (irreversível, mas só didático).
- `main.py`: menu para testar tudo no terminal.
- `index.html`: demo online do hash (roda no GitHub Pages).

## Como executar

```
python main.py
```

## Demo online

Ative o GitHub Pages (Settings → Pages → branch `main`) e abra o link gerado.

> O GitHub Pages não executa Python, por isso a demo web usa JavaScript com a mesma lógica.
